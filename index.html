    Remote control

    Run the service from an iPad or phone: it shows Live and Next up, and every tap there changes this laptop and the projector. Works on a different Wi-Fi or mobile data. Both devices just need internet.

    Privacy & relay

    Messages pass through a public relay (ntfy.sh) but are encrypted end-to-end with a key made from the pairing code, so the relay can't read song or slide content. Anyone with the code can control the screen, so press New code if it leaks.

    Narrative

    A browser-based lyrics and scripture presenter. Your songs, Bibles and settings live in this browser (IndexedDB). Use Export for backups.

    Projector: the first time, Chrome asks to “manage windows on all your displays”. Allow it, and Narrative opens the output on the second screen by itself.
